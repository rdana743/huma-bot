# Бот Huma Marketing для MAX

Воронка: реклама → канал Huma Marketing в MAX → бот в MAX → заявка или оплата.

В постах канала ставьте ссылку на бота с меткой: `https://max.ru/<имя_бота>?start=post1`.

## Что умеет бот

- **Главное меню** с кнопками: калькулятор, гайды и услуги, связаться, канал.
- **Калькулятор потерь со звонков**: 3 вопроса → конверсия звонка в запись и сколько денег клиника недополучает в месяц → предложение бесплатного разбора.
- **Каталог** гайдов и услуг с кнопкой «Оплатить» (ссылка на ЮKassa или Prodamus) или «Оставить заявку».
- **Заявки**: человек отправляет номер кнопкой или текстом. Вам приходит сообщение с темой, телефоном, цифрами из калькулятора и источником.
- **Метки источника**: ссылка `https://max.ru/<имя_бота>?start=tg_post1` запоминает, откуда пришёл человек.
- **/stats** (только для админов): пользователи и заявки по источникам.
- **/id**: узнать свой ID в MAX.

## Запуск на Mac

Нужен Node.js 20.19 или новее (проверить: `node -v`, установить: https://nodejs.org).

```bash
cd ~/Documents/GitHub/chatbot
npm install
npm start
```

Затем:

1. Напишите боту в MAX `/id` и скопируйте число.
2. Впишите его в `.env` в строку `ADMIN_USER_IDS=`.
3. Остановите бота (Ctrl+C) и запустите снова: `npm start`.

Теперь заявки будут приходить вам в MAX.

## Что настроить

| Что | Где |
| --- | --- |
| Тексты, продукты, цены | `src/catalog.js` |
| Ссылка на оплату гайда | `.env` → `PAY_URL_GUIDE_CALLS` |
| Кто получает заявки | `.env` → `ADMIN_USER_IDS` |
| Заявки и пользователи | папка `data/` (создаётся сама) |

## Проверка без MAX

```bash
npm test
```

Прогоняет все сценарии с имитацией API MAX.

## Ограничения текущей версии

- Бот работает, пока открыт терминал. Для постоянной работы нужен сервер (VPS) и webhook — следующий шаг.
- В MAX нет встроенных платежей, поэтому оплата идёт по внешней ссылке. Автоматически выдавать гайд после оплаты можно через уведомления ЮKassa — тоже следующий шаг.
- Заявки хранятся в JSON-файлах. При росте перейдём на базу данных.

## Telegram-бот

Тот же сценарий, что в MAX: приветствие с кнопкой мини-приложения, /menu с калькулятором и каталогом, заявки, /stats.

```bash
npm run start:tg
```

1. Напишите Telegram-боту `/id` и впишите число в `.env` → `TG_ADMIN_IDS=`.
2. Перезапустите (`Ctrl + C`, `npm run start:tg`) — заявки из Telegram будут приходить вам в Telegram.

Оба бота можно держать запущенными одновременно в двух окнах Терминала. Статистика и заявки — общие (`data/`).
